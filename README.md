# spring-ai-chatbot

A lightweight Spring Boot service integrating Spring AI to process user queries via LLM backends.

## Features
- REST Controller exposing AI chat endpoints.
- Integration with Spring AI ChatClient.
- Service layer handling user prompts and response handling.

## Prerequisites
- Java 17 or higher
- Maven 3.x
- An API Key for your LLM provider (e.g., OpenAI, Anthropic, Ollama)
